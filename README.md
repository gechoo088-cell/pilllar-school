# Pillar Academy School Website

A modern, responsive school website for Pillar Academy showcasing programs, faculty, admissions, and school information.

## Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Homepage** - Welcome section with hero banner
- **About Section** - School mission, vision, and values
- **Programs** - Information about academic programs
- **Faculty** - Teacher profiles and expertise
- **Admissions** - Enrollment information and process
- **Contact** - Contact form and location information
- **News & Events** - Latest school updates and calendar

## Project Structure

```
pilllar-school/
├── index.html          # Main homepage
├── style.css           # Global styles and responsive design
├── script.js           # Frontend functionality
├── .gitignore          # Git ignore file
└── README.md           # Project documentation
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/gechoo088-cell/pilllar-school.git
   cd pilllar-school
   ```

2. Open `index.html` in your web browser or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   ```

3. View at `http://localhost:8000`

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Flexbox, Grid, and responsive design
- **JavaScript** - Interactivity and form handling

## Customization

- Update school name, colors, and branding in `style.css`
- Modify navigation and content in `index.html`
- Add school logo and images to enhance visual appeal
- Update contact information and social media links
